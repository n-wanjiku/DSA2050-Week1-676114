## Project Objective
Perform baseline descriptive analysis on Kenya retail order data to quantify key revenue metrics, evaluate regional and product distribution, and deliver actionable operational insights to management.

## Three KPIs Used
- **Total Revenue:** KES 3,206,450.00
- **Total Transactions:** 300 orders
- **Average Transaction Value (ATV):** KES 10,688.17

## Key Findings
1. Gross revenue relies heavily on a narrow group of top-performing SKUs.
2. Sales distribution exhibits key concentration across top product categories and primary regional channels.
